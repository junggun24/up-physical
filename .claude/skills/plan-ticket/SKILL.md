# 기획 티켓 작성

## 절차

1. **맥락 로드** — `.harness/wiki/planning.md` 를 읽고 핵심 경로·차별화 4종·현재 가정을 확인한다.
2. **중복 확인** — Notion 작업 보드(업 피지컬 페이지 하위)에서 유사 티켓을 검색한다.
3. **티켓 작성** — 아래 템플릿을 채운다:

```
제목: <동사로 시작, 결과 중심>
목표(What): 사용자/시스템 관점에서 무엇이 되는가
Why: 핵심 경로(P0→P4) 또는 차별화 4종과의 연결. 왜 지금인가.
제약: 기술(계약·플랫폼)·정책·일정
완료조건: 검증 가능한 기준만.
  - [ ] Invariant/Golden/측정치 형태 (예: "fixture X에 대해 결과 Y", "처리시간 < N초")
  - [ ] "동작한다", "개선된다" 같은 모호한 표현 금지
Phase: P0~P4 중 하나 / 우선순위: 상·중·하
```

4. **검증** — 완료조건이 QA가 그대로 실행할 수 있는 수준인지 자문한다. 아니면 다시 쓴다.
5. **환류** — 새로 결정된 제품 방향·가정 변경은 `.harness/wiki/planning.md`에 반영한다.

## 완료 판정

- 티켓에 4요소(What/Why/제약/완료조건)가 모두 있고, 완료조건이 측정 가능하다.
