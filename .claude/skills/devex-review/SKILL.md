# DevEx 리뷰 — 클론부터 첫 성공까지

관점: "이 리포를 처음 받은 사람/에이전트"가 되어 **문서만 보고** 실제로 따라 한다.

## 1. 실측 시나리오 (전부 실행 — 읽기만 금지)

1. 클론 → `AGENTS.md` 만 읽고 다음 할 일을 알 수 있나? (Context 도달 시간 기록)
2. `RUN.md` 처음 한 번 절차를 그대로 실행 → 막히는 지점·누락 전제 기록
3. `.harness/runners/setup.sh` → `check.sh` → `smoke.sh` 각각 첫 시도 성공 여부
4. 일부러 실수 1개 (규칙 위반 커밋 등) → 에러 메시지가 스스로 고칠 수 있게 안내하나?
5. "X는 어디 있지?" 3문 랜덤 테스트 (예: 멱등성 규칙? 엔진 프로토콜? 시드 방법?)
   → wiki grep으로 30초 내 도달하나?

## 2. 채점

| 항목 | 측정 |
| --- | --- |
| 첫 성공까지 시간 | 클론 → smoke 통과까지 단계 수·막힘 수 |
| 에러의 친절함 | 막혔을 때 메시지가 다음 행동을 알려주나 |
| 문서-현실 일치 | 문서대로 했는데 다른 결과가 나온 곳 (Trust Rule 위반 후보) |
| 검색성 | 3문 테스트 통과율 |

## 3. 산출

- 마찰마다: [P1 온보딩 차단 / P2 시간 낭비 / P3 거슬림] + 구체 수정안.
- 문서-현실 불일치는 **즉시 수정** (코드가 진실).
- 반복 마찰은 러너/스킬 자동화 티켓으로. 결과 요약을 환류 로그에 1항목.
