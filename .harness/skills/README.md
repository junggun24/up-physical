# skills — 재사용 절차기억 (How)

반복 작업 절차를 md 로 축적한다. 3회 이상 반복되는 절차가 후보다.

형식: 파일 1개 = 절차 1개. `언제 쓰나 / 전제 / 단계 / 검증` 순서로 짧게.

## 후보 (환류 대기)

- `add-invariant.md` — 계약 불변식 추가 절차 (contracts 원본 동기화 → Go 이식 → 테스트 → fixture)
- `seed-reference.md` — 레퍼런스 시드 등록 절차 (cmd/seed + MinIO)
- `add-endpoint.md` — API 엔드포인트 추가 절차 (핸들러 → store → 검증 게이트)
